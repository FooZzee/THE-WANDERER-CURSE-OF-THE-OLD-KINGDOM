Трёхмерная экшен-RPG в жанре тёмного фэнтези от третьего лица, работающая прямо в браузере на базе **Three.js**, **React 19** и **TypeScript**, а также включающая нативную 3D-версию для движка **Godot 4.x** (`/godot`).

Вы играете за **Корвуса** — охотника на чудовищ из Школы Ворона, прибывшего в проклятое приграничье Старого Королевства, чтобы расследовать природу Пепельного Затмения, сокрушить легионы Братства Пепла и остановить пробуждение сущности Пустоты в Долине Звездопада.

## 📦 Готовые архивы проекта (Web и Godot 4.x)

В директории `public/` доступны готовые к скачиванию архивы:
- **`public/the-wanderer-godot.zip`** — полный архив 3D-проекта для **Godot Engine 4.x** (`project.godot`, сцены `.tscn`, скрипты `.gd`, ресурсы `.tres`).
- **`public/the-wanderer-web.zip`** — готовая статическая Web-сборка (`index.html` + `assets/`) для мгновенного запуска или загрузки на GitHub Pages / itch.io / Netlify / Vercel.

Скачать оба архива можно также прямо из главного меню игры или модального окна **Настройки (Settings)**.

## ✨ Ключевые особенности v2.0.0

### 🌍 Масштабный бесшовный мир, 8 регионов и 3 Акта сюжета
- **Деревня Воронья Падь (Crow Hollow) и 6 укреплённых поселений** — все населённые пункты обнесены деревянным частоколом с арочными воротами и факелами. Внутри и вокруг поселений действует безопасная буферная зона: монстры не спавнятся в деревнях и физически не могут зайти за частокол или через ворота.
- **Старый Лес, Проклятое Святилище, Разрушенная Крепость и Пепельный Погост** — классические регионы I Акта с подземными Катакомбами Древних Королей.
- **Северный Поход (Акт II)**:
  - **Тракт Висельников и Затопленные Топи** — болотистая низина с деревянными мостками, тонущими обозами, хижинами на сваях и логовом Болотной Гидры.
  - **Среброзубый Перевал и Мёртвые Шахты** — заснеженный горный серпантин с расщелинами, висячими мостами, Чёрной Рудой и Кристальным Колоссом.
  - **Чёрный Бастион Братства Пепла** — цитадель охотников с крепостными стенами, внутренними дворами, плацем и алхимической лабораторией.
  - **Кратер Затмения и Зал Трона Пустоты** — эпицентр катастрофы с парящими обсидиановыми островами и ареной Аватара Пустоты.
- **Новые регионы и Акт III («Сердце Звездопада»)**:
  - **Затонувший Порт Сольхейм (Запад, `x: -150, z: 0`)** — прибрежная гавань с каменным пирсом, затонувшими галеонами, маяком, смотрителем Хальваром и контрабандисткой Сигрид.
  - **Солнечный Монастырь Ордена Алого Солнца (Восток, `x: 155, z: -15`)** — горное плато с собором, колокольней, солнечными часами и аббатом Аврелием.
  - **Долина Звездопада (Дальний Север, `x: 0, z: -620`)** — метеоритный кратер III Акта с обсидиановыми монолитами, Небесной Кузницей и финальным квестом `quest_act3_starfall_heart`.

### 🌤️ Динамический Skybox, небесные светила и облачность
- Процедурный купол неба (`computeSkyboxState`) плавно меняет градиенты зенита, горизонта и дымки в зависимости от игрового времени суток (`dawn`, `day`, `dusk`, `night`) и погоды (`clear`, `fog`, `rain`).
- **Небесные тела**: вращающиеся по 24-часовой дуге Солнце с короной, Луна с пепельным гало и мерцающее звёздное поле из 420 светил.
- **Объёмный облачный слой**: двухслойное кольцо из 28 облачных кластеров, меняющее плотность, прозрачность, скорость ветра и освещённость при переходе от ясной погоды к туману и грозе.
- **Динамические тени (PCFSoftShadowMap)**: реальные тени от Солнца/Луны и локальных костров/факелов.

### 💥 Визуальная отдача боя (Screen-Shake) и мобильная тактильная вибрация (`navigator.vibrate`)
- **3D-тряска камеры и экранный импульс (`computeCombatScreenShake`)**:
  - Критические удары игрока и тяжёлые атаки боссов/элитных чудовищ вызывают физическую тряску камеры по осям X/Y/Z, наклон горизонта (Dutch roll), динамический рывок угла обзора (FOV punch) и экранную вспышку-виньетку (золотую при крите, багровую при тяжёлом ранении).
- **Тактильная отдача для мобильных платформ (`computeCombatHapticPattern` + `navigator.vibrate`)**:
  - На мобильных устройствах (Android / мобильные браузеры / режим управления `mobile`) критические попадания игрока вызывают многоимпульсную вибрацию (`[40, 25, 70]` мс / `[55, 30, 95]` мс для тяжёлого крита), а получение тяжёлого урона от врагов — мощный тактильный импульс (`[85, 40, 125]` мс).

### ⚡ Стабильные 60 FPS
- **Пространственное хеширование (`SpatialGrid`)** для коллизий, кэширование геометрии и материалов, `THREE.InstancedMesh` для лесных массивов и декораций, а также дистанционный троттлинг ИИ и анимаций обеспечивают стабильные **60 FPS**.

## 🎮 Управление (ПК и Мобильные устройства)

| Клавиша / Действие | Назначение |
| :---: | :--- |
| **`W` `A` `S` `D` / Сенсорный джойстик** | Передвижение персонажа |
| **`Shift`** | Спринт |
| **`Пробел (Space)`** | Уклонение / Перекат с окном неуязвимости (i-frames) |
| **`ЛКМ` / Удержание `ЛКМ`** | Быстрая атака / Тяжёлая атака мечом |
| **`ПКМ`** | Блок / Парирование мечом |
| **`1` / `2`** | Выхватить **Стальной меч** (люди/звери) / **Серебряный меч** (чудовища/призраки) |
| **`Q` / Колесо мыши (`3`–`7`)** | Переключить активный Знак Пепла (**Пламя**, **Барьер**, **Импульс**, **Иллюзия**, **Стужа**) |
| **`R`** | Сотворить выбранный Знак Пепла |
| **`F` / `H`** | Выпить эликсир исцеления («Ласточка») |
| **`G`** | Отдать приказ напарнику / Выпить боевой эликсир |
| **`V`** | **Зрение Зольника** (подсветка улик, сундуков, трав и следов) |
| **`E`** | Взаимодействие (поговорить с NPC, открыть сундук, собрать траву, осмотреть улику) |
| **`I` / `J` / `M` / `B` / `L` / `N`** | Инвентарь / Квесты / Карта мира / Бестиарий / Кодекс / Алхимия |
| **`Esc`** | Меню паузы и настроек |

## 🚀 Установка, тестирование и публикация на GitHub

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/your-username/the-wanderer-curse-of-the-old-kingdom.git
cd the-wanderer-curse-of-the-old-kingdom
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте в браузере адрес `http://localhost:3000`.

### 3. Проверка типов и запуск 31 модульного теста
```bash
npm run lint
npm test
```

### 4. Сборка для продакшена и GitHub Pages
```bash
npm run build
```
В репозитории уже настроен workflow **`.github/workflows/deploy.yml`**, который при каждом `git push` в ветку `main` или `master` автоматически запускает проверку типов, прогоняет все модульные тесты (`npm test`), собирает проект и публикует его на **GitHub Pages**.
