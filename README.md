Трёхмерная экшен-RPG в жанре тёмного фэнтези от третьего лица, работающая прямо в браузере на базе **Three.js**, **React 19**, **Express** и **TypeScript**, с поддержкой живого голосового общения с NPC через микрофон и генеративным ИИ, а также включающая нативную 3D-версию для движка **Godot 4.x** (`/godot`).

Вы играете за **Корвуса** — последнего Зольника из Школы Ворона, прибывшего в проклятое приграничье Старого Королевства Вальдмарк, чтобы расследовать природу Пепельного Затмения, сокрушить легионы Братства Пепла и решить судьбу мира.

## 📦 Готовые архивы проекта (Web, GitHub Source и Godot 4.x)

В директории `public/` (а также по кнопкам на титульном экране игры) доступны свежие сборки **v3.0.0**:
- **`public/the-wanderer-web.zip`** — готовая статическая Web-сборка (`index.html`, `assets/`, документация) для мгновенного запуска и публикации на **GitHub Pages / itch.io / Netlify / Vercel**.
- **`public/the-wanderer-github.zip`** — полный архив исходного кода репозитория для публикации на **GitHub** (`src/`, `server.ts`, `godot/`, `.github/workflows/deploy.yml`, `package.json`, `README.md`, тесты).
- **`public/the-wanderer-godot.zip`** — полный архив 3D-проекта для **Godot Engine 4.x** (`project.godot`, сцены `.tscn`, скрипты `.gd`, ресурсы `.tres`).

Пересобрать все три ZIP-архива в любой момент можно командой:
```bash
npm run pack:zip
```

## ✨ Ключевые особенности v3.0.0

### 🧠 Живой когнитивный ИИ NPC, голосовое общение по микрофону и система отношений
- **Разговор голосом по-русски через микрофон**: нажмите кнопку микрофона в диалоге или рядом с любым NPC, говорите по-русски — система распознаёт речь (`SpeechRecognition` + серверный фолбэк `MediaRecorder` / Gemini Audio) и генерирует осмысленный ответ.
- **Озвучка всех персонажей по полу (Мужские и Женские голоса)**:
  - Все NPC отвечают **и текстом, и голосом**.
  - Мужские персонажи озвучиваются мужскими голосами (глубокий бас кузнеца и рудокопов, баритон старост и стражей, живой тенор-баритон стримера FooZzee и бардов).
  - Женские персонажи озвучиваются женскими голосами (тёплое меццо травницы Марфы и жриц, мистическое сопрано архидруида Эловен и матриарха Ростовой, звонкий голос Лиры и Сигрид).
- **Уникальная личность, память и внутренние мысли (`thoughtProcess`)**:
  - Каждый NPC обладает собственной биографией, характером, секретами и увлечениями, обдумывает реплики игрока и никогда не отвечает одной и той же заученной фразой.
- **Дружба, ссоры и романтика с любым NPC**:
  - С каждым персонажем можно **подружиться**, **поругаться**, **помириться**, **флиртовать**, **закрутить роман** и **влюбить в себя** (стадии от *Незнакомца* и *Соперника* до *Верного друга*, *Возлюбленного(ой)* и *Родственной души*).
- **Автоматическое закрытие диалога после голосового ответа**: по завершении озвучки реплики диалоговое окно плавно закрывается автоматически.

### 🌫️ Динамический туман, мягкое свечение (Bloom), физика и оптимизация боя
- **Динамическая плотность тумана (`Fog Intensity`)**: реагирует на время суток (утренние и ночные туманы), биом и события исследования (вход в святилище, катакомбы, активация путевых камней), настраивается ползунком в меню **Настройки → Основные**.
- **Сбалансированное свечение (`Bloom Intensity`)**: переработанный контур пост-обработки `UnrealBloomPass` без засветки экрана с плавной регулировкой в настройках.
- **Дистанционное отсечение звуков и урона стражников (`shouldEmitGuardCombatFeedback`)**: если стражники сражаются с монстрами вдалеке (> 20 м от игрока), всплывающий урон и звуки ударов не спамят экран и эфир — они появляются только при приближении героя.
- **Непроходимые стены и заборы (`resolveSlidingCollision`)**: суб-шаговая проверка коллизий исключает прохождение сквозь стены, здания и частоколы деревень даже при рывках и перекатах.
- **Органика персонажей и монстров**: сглаженные анатомические 3D-модели людей и чудовищ вместо угловатых примитивов + мрачный готический саундтрек (виолончельный дрон, колокола и эхо руин).

| Клавиша / Действие | Назначение |
| :---: | :--- |

| **`Shift`** | Спринт |

## 🚀 Публикация на GitHub и запуск проекта

### Вариант А: Быстрая публикация через готовый архив `the-wanderer-github.zip`
1. Скачайте **`the-wanderer-github.zip`** прямо из главного меню игры (или возьмите из `public/the-wanderer-github.zip`).
2. Распакуйте архив в новую папку и выполните:
```bash
git init
git add .
git commit -m "feat: release The Wanderer v3.0.0 with Voice AI, Streamer FooZzee & Act IV Biomes"
git branch -M main
git remote add origin https://github.com/<ваш-аккаунт>/<ваш-репозиторий>.git
git push -u origin main
```
3. В настройках репозитория на GitHub перейдите в **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Workflow `.github/workflows/deploy.yml` автоматически соберёт проект и опубликует его на GitHub Pages!

### Вариант Б: Локальная разработка и сборка
```bash
npm install
npm run dev      # Запуск полного сервера (Express + Vite + AI Voice API) на http://localhost:3000
npm run lint     # Проверка типов TypeScript (tsc --noEmit)
npm test         # Запуск всех 39 модульных и интеграционных тестов
npm run build    # Продакшен-сборка фронтенда в папку dist/
npm run pack:zip # Пересборка архивов public/the-wanderer-web.zip, the-wanderer-github.zip и the-wanderer-godot.zip
```
