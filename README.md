# ⚔️ Странник: Проклятие Старого Королевства
*(The Wanderer: Curse of the Old Kingdom)*

Трёхмерная экшен-RPG в жанре тёмного фэнтези от третьего лица, работающая прямо в браузере на базе **Three.js**, **React 19** и **TypeScript**.

Вы играете за **Корвуса** — охотника на чудовищ из Школы Ворона, прибывшего в проклятое приграничье Старого Королевства, чтобы расследовать природу Багрового Затмения, сокрушить Братство Пепла и остановить пробуждение сущности Пустоты.

---

## ✨ Ключевые особенности

### 🌍 Масштабный бесшовный мир и 5 проработанных зон
- **Деревня О크хейвен и окрестности** — укреплённое поселение с таверной, кузницей, лавкой травницы, доской объявлений, сторожевыми башнями и мельницей.
- **Биом 1: Тракт Висельников и Затопленные Топи** — мрачные болота с полуразрушенными деревянными мостками, тонущими обозами, клетками на виселицах, рыбацкими хижинами на сваях, зарослями камыша и ядовитыми испарениями.
- **Биом 2: Среброзубый Перевал и Мёртвые Шахты** — заснеженный горный серпантин с расщелинами, висячими мостами, еловыми рощами и подземными штольнями с рельсами, вагонетками и мерцающими кристаллами.
- **Биом 3: Чёрный Бастион Братства Пепла** — массивная цитадель с крепостными стенами, внутренними дворами, сожжёнными казармами, тренировочным плацем и алхимической лабораторией.
- **Биом 4: Кратер Затмения и Зал Трона Пустоты** — сюрреалистичный эпицентр катастрофы с парящими обсидиановыми островами, потоками багровой энергии, древними алтарями и ареной финального босса.
- **Точки интереса (`?`)** — в каждом биоме расположены лагеря мародёров, охраняемые кованые сундуки с сокровищами, Места Силы, тайники и квестовые улики.

### ⚔️ Боевая система в духе классических охотников на чудовищ
- **Два меча с полноценной сменой и анимацией**:
  - **Стальной меч (`1`)** — 100% урона против людей (разбойников, дезертиров, фанатиков Братства Пепла) и диких зверей (волков).
  - **Серебряный меч (`2`)** — 100% урона против порождений тьмы (упырей, болотных топленников, призраков, пепельных големов и боссов).
  - Оба меча отображаются в ножнах за спиной Корвуса; переключение сопровождается процедурной анимацией выхватывания клинка, металлическим звоном и руническим свечением.
- **Тактический ближний бой**: быстрые (`ЛКМ`) и тяжёлые (`ПКМ`) удары с комбо-сериями, парирование/блок, уклонение перекатом с окном неуязвимости (i-frames) и расход выносливости.
- **Умный HUD-советник**: автоматически подсказывает, какой клинок эффективен против текущей цели.

### 🔮 Магические Знаки
Четыре боевых Знака с визуальными эффектами частиц и тактическим применением:

| Клавиша | Знак | Эффект |
| :---: | :--- | :--- |
| **`Q`** | 🔥 **Игни (Igni)** | Выпускает конус пламени, наносящий урон огнём и поджигающий врагов перед игроком |
| **`Z`** | 🛡️ **Квен (Quen)** | Окружает Корвуса энергетическим щитом, поглощающим входящий урон |
| **`X`** | 💨 **Аард (Aard)** | Телекинетический импульс, отбрасывающий и оглушающий противников, сбивающий защиту |
| **`C`** | 🟣 **Ирден (Yrden)** | Создаёт на земле магический глиф, замедляющий врагов и делающий призраков уязвимыми |

### 🎒 Инвентарь, алхимия, крафт и прокачка
- **Эксклюзивные слоты экипировки**: стальной меч, серебряный меч, доспех и трофей чудовища с автоматическим пересчётом характеристик атаки, брони и бонусов.
- **Кузнечное дело и алхимия**: ковка клинков и лат по чертежам, варка эликсиров («Ласточка», «Гром», «Кошка») и боевых масел.
- **Древо талантов**: развитие веток фехтования, магии Знаков и алхимической стойкости за очки навыков.
- **Бестиарий и Глоссарий**: подробные записи о каждом типе врагов, их уязвимостях к маслам, Знакам и типам оружия, а также хроники мира.

### 🗣️ Живые NPC, нелинейные диалоги и квесты
- **Анатомические 3D-модели персонажей**: иерархический скелет с процедурной анимацией дыхания, поворотом головы к игроку, одеждой по роли и уникальным реквизитом (кузнец с молотом, староста с посохом, травница с корзиной зелий, стражники с алебардами).
- **Сюжетная кампания и ведьмачьи заказы**: многоступенчатые квесты, расследование улик с помощью **Магического Чутья (`V`)**, доска объявлений и контракты на боссов.
- **Система сохранений (`F5` / `F9`)**: автосохранение и ручные слоты сохранения прогресса, инвентаря, состояния сундуков и квестов в `localStorage`.

## 🎮 Управление

| Клавиша / Действие | Назначение |
| :---: | :--- |
| **`W` `A` `S` `D`** | Передвижение персонажа |
| **`Shift`** | Спринт |
| **`Пробел (Space)`** | Уклонение / Перекат (либо прыжок вне боя) |
| **`Мышь`** | Вращение камеры (при захвате курсора) |
| **`ЛКМ`** | Быстрая атака мечом |
| **`ПКМ`** | Тяжёлая атака / Комбо-удар |
| **`1`** | Достать / сменить на **Стальной меч** (против людей и зверей) |
| **`2`** | Достать / сменить на **Серебряный меч** (против чудовищ и призраков) |
| **`Q` / `Z` / `X` / `C`** | Сотворить Знак (**Игни** / **Квен** / **Аард** / **Ирден**) |
| **`R`** | Выпить эликсир исцеления («Ласточка») |
| **`F`** | Использовать эликсир силы («Гром») |
| **`V`** | **Магическое чутьё** (подсветка улик, сундуков, трав и следов) |
| **`E`** | Взаимодействие (поговорить с NPC, открыть сундук, собрать траву, осмотреть улику) |
| **`Tab` / `I`** | Открыть меню персонажа (Инвентарь, Квесты, Алхимия, Навыки, Бестиарий, Карта) |
| **`M`** | Открыть карту мира и быстрое перемещение по открытым указателям |
| **`F5` / `F9`** | Быстрое сохранение / Быстрая загрузка |
| **`Esc`** | Меню паузы и настроек |

## 🚀 Установка и запуск

### Предварительные требования
- **Node.js** версии `18.x` или выше
- **npm** версии `9.x` или выше

### 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com/your-username/the-wanderer-rpg.git
cd the-wanderer-rpg
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте в браузере адрес `http://localhost:3000`.

### 3. Проверка типов и запуск тестов
```bash
# Проверка TypeScript без генерации файлов
npm run lint

# Запуск модульных тестов боевой математики и экипировки
npm test
```

### 4. Сборка для продакшена (Web-публикация)
```bash
npm run build
```
Готовая оптимизированная сборка будет создана в папке `dist/`. Благодаря настройке `base: './'` в `vite.config.ts`, содержимое папки `dist/` можно разместить на **GitHub Pages**, **Vercel**, **Netlify**, **itch.io** или любом статическом веб-сервере в любой подпапке.

Для локального предпросмотра собранной версии:
```bash
npm run preview
```

## 🛠️ Технологический стек

- **Рендеринг и 3D-графика**: [Three.js](https://threejs.org/) (процедурная геометрия, PBR-материалы, динамическое освещение, кастомные системы частиц)
- **Интерфейс**: [React 19](https://react.dev/) + [Tailwind CSS v4](https://tailwindcss.com/) + [Lucide Icons](https://lucide.dev/)
- **Звук**: Процедурный аудио-движок на базе нативного **Web Audio API** (не требует загрузки внешних аудиофайлов)
- **Язык и сборка**: [TypeScript](https://www.typescriptlang.org/) + [Vite 8](https://vite.dev/)
